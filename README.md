## Practicals

The practicals folder contains simple implementations created to understand basic agent behavior through code.

### Learning Agent

Demonstrates an agent that improves its behavior based on feedback and previous outcomes.

Concepts practiced:

- Agent-environment interaction
- Feedback-based learning
- Updating behavior over time
- Learning from previous actions

### Simple Reflex Agent

Demonstrates a rule-based agent that reacts directly to the current environment using predefined condition-action rules.

Concepts practiced:

- Simple Reflex Agent architecture
- Condition-action rules
- Environment perception
- Immediate decision-making without memory
