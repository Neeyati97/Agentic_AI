# Agentic AI Practicals

This folder contains the practical exercises I completed while learning the fundamentals of Agentic AI.

These implementations were created for learning and study purposes to understand how different types of AI agents behave and make decisions.

---

## 01 — Learning Agent

A basic implementation of a learning agent that improves its behavior based on feedback and previous outcomes.

### Concepts Practiced — Learning Agent

- Agent-environment interaction
- Feedback-based learning
- Updating behavior over time
- Learning from previous actions

---

## 02 — Simple Reflex Agent

A simple rule-based agent that reacts to the current environment using predefined condition-action rules.

### Concepts Practiced — Simple Reflex Agent

- Simple Reflex Agent architecture
- Condition-action rules
- Environment perception
- Immediate decision-making without memory

---

## Purpose

These practicals were completed as part of my Agentic AI learning journey to understand the core behavior of intelligent agents through simple implementations.

The focus of these exercises is on understanding the concepts through code rather than building complete applications.
